Chat with Your Local LLMs

Features

🔌

Easy Connection

Connect to your local Ollama instance with just a few clicks. No complex configuration required.

🤖

Model Selection

Choose from any model installed in your Ollama instance. The app automatically detects available models.

💬

Chat Interface

Send prompts and view responses in a clean, user-friendly interface with proper markdown rendering.

🔒

Privacy-Focused

All communication happens locally. Your data never leaves your computer.

📱

Desktop App

Available as a native desktop application for macOS. No browser or CORS issues.

📝

Markdown Support

Responses properly render markdown formatting, including code blocks, lists, and tables.

How to Use

1

Install the Application

Download the DMG file, open it, and drag the application to your Applications folder.

2

Start Ollama

Make sure Ollama is running on your computer. The default URL is http://localhost:11434.

3

Connect to Ollama

Open the application, enter your Ollama URL, and click "Connect".

4

Select a Model

Choose from the available models detected from your Ollama instance.

5

Start Chatting

Enter your prompt and click "Send Prompt" to start chatting with your local LLM.

Frequently Asked Questions

Is my data secure?

Yes. All communication happens locally between the app and your Ollama instance. No data is sent to external servers.

Why do I see a security warning?

The app isn't signed with an Apple Developer certificate. To open it, go to System Preferences → Security & Privacy and click "Open Anyway".

Which models are supported?

Any model that works with Ollama is supported. The app will automatically detect all models installed in your Ollama instance.

Do I need an internet connection?

No, the app works entirely offline as long as Ollama is running on your computer.

Is Windows support coming?

Yes, Windows support is planned for a future release.

How do I report issues?

Please report any issues on the GitHub repository.
